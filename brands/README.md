# Integration icon

Original icon for the `solix_ble` integration (power-station + energy bolt with a
generic wireless motif). No third-party logos or trademarks are used.

- `solix_ble_icon.svg` — editable source.
- `custom_integrations/solix_ble/icon.png` (256×256) and `icon@2x.png` (512×512).

To make Home Assistant display it, submit these PNGs to the
[home-assistant/brands](https://github.com/home-assistant/brands) repository at
`custom_integrations/solix_ble/icon.png` and `icon@2x.png`. Home Assistant serves
integration icons from `https://brands.home-assistant.io/`; they cannot be shipped
inside the integration itself.
